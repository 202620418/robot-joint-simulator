유압식 vs 전기식 로봇 관절 제어 실험 시뮬레이터

이 파일은 보고서용 직접 조작형 시뮬레이터이다. 실제 아틀라스 내부 데이터를 재현한 것이 아니라, 로봇 관절 하나가 목표 각도까지 움직이는 과정을 단순화하여 비교한다. 실행 버튼을 누르면 로봇 팔이 직접 움직이고, 실험 결과가 기록된다.

실험 조건 설정

사용 방법: 구동 방식을 고르고 실험 시작을 누른다. 로봇 팔이 목표 각도까지 움직이는 모습을 본 뒤, 현재 결과 기록 버튼을 누르면 표에 저장된다.

아직 실험을 시작하지 않았다.
